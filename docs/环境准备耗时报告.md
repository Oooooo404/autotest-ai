环境准备耗时对比报告



一、背景

&#x20;      在接口自动化测试项目中，环境搭建是重复且耗时的环节。传统手工搭建需要逐项安装依赖、配置数据库、设置环境变量，过程繁琐且容易出错。

&#x20;      本项目通过 Dockerfile 将测试框架镜像化，实现"一键部署运行"。



二、对比数据

| 方式 | 步骤 | 耗时 |

| :--- | :--- | :--- |

| 手工搭建| 装 Python → 装依赖 → 配数据库 → 配环境变量 → 调试 | 约 2 小时 |

| Docker 一键 | `docker build` + `docker run` | 约 15 秒 |



三、手工搭建的具体步骤

1\. 安装 Python 3.11（约 5 分钟）

2\. 安装依赖：pytest、requests、PyYAML、jsonpath-ng、Faker、pymysql、pytest-html、jsonschema、dbutils（约 10 分钟）

3\. 安装并配置 MySQL（约 30 分钟）

4\. 安装并配置 Redis（约 15 分钟）

5\. 配置环境变量、数据库连接（约 20 分钟）

6\. 调试环境问题（约 40 分钟）

合计：约 2 小时



四、Docker 一键部署的具体步骤

1\. 构建镜像

docker build -t autotest-ai .

2\. 运行容器

docker run autotest-ai

合计：约 15 秒



五、结论

环境准备耗时由 2 小时降至 15 秒，效率提升约 480 倍。

Docker 镜像化保证了环境一致性，避免"在我电脑上能跑"的问题。

新人加入项目时，只需执行两条命令即可运行完整测试。



六、效果数据
